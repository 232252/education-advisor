功能使用指南

每一个功能模块的详细使用方法与典型使用场景，帮助你把 Education Advisor 的能力用满用好。

目录

快速上手

从安装到跑通第一个 AI 任务，只需要几分钟。

安装与首次启动 步骤

  1. 下载安装包：前往下载页获取对应平台的安装包（Windows / macOS / Linux），双击安装。
  2. 首次启动向导：首次启动会进入 Onboarding 向导，依次完成班级创建 → 学生导入 → 模型配置 三步初始化。
  3. 创建班级：输入班级名称（如「高一(3)班」），系统自动创建班级命名空间，所有数据按班级隔离。
  4. 导入学生：选择 Excel 批量导入或手动逐个添加，学生姓名支持拼音检索。
  5. 配置模型：在「模型」页面选择 LLM 提供商并填入 API Key（详见模型管理），完成连接测试。
  6. 开始使用：进入仪表盘或 AI 对话页，开始你的第一个智能体任务。

使用场景 场景

新学期开班

开学第一周，通过向导创建新班级、Excel 导入全班学生名单，10 分钟内完成班级数字化底座搭建。

接手二手班级

中途接手其他老师的班级，先导入学生名单与历史成绩，再让「数据分析师」智能体生成班级现状报告，快速摸底。

所有数据保存在本地（%APPDATA%/education-advisor / ~/Library/Application Support/education-advisor），卸载重装不丢失。

仪表盘

班级全局视图一屏尽览：关键指标、风险分布、分数趋势。

使用步骤 步骤

  1. 点击左侧导航「仪表盘」进入。
  2. 顶部切换班级（多班级场景），或选择「全部班级」查看汇总。
  3. 查看核心指标卡：学生总数、本周事件数、平均操行分、风险学生数。
  4. 浏览风险等级分布饼图与操行分数分布柱状图，点击图块可查看学生明细。
  5. 「最新动态」面板展示最近事件流，点击学生名跳转学生档案。

使用场景 场景

每日晨检

早自习前打开仪表盘 30 秒扫一眼：昨日事件、风险学生变化，决定今天重点关注哪些学生。

周例会汇报

周五班会前截图风险分布与分数趋势图，作为班级周总结的可视化素材。

学生管理

学生信息、日常事件（加扣分）、批量导入导出的统一入口。

添加与管理学生 步骤

  1. 进入「学生」页面，点击「添加学生」。
  2. 填写姓名、学号、性别等基本信息（姓名必填）。
  3. 在学生列表点击任一学生进入学生档案，查看事件流、学业数据、AI 分析。
  4. 支持搜索、按班级筛选、批量选择操作（调班 / 删除）。

Excel 批量导入 步骤

  1. 点击「导入」→「Excel 导入」，选择 .xlsx 文件。
  2. 系统自动解析并弹出预览：显示将导入的学生（姓名 / 学号 / 班级），错误行单独列出原因。
  3. 确认无误后点击「确认导入」，进度条实时显示导入进度。
  4. 重名学生与已存在学生会标记冲突，可选择跳过或覆盖。

记录日常事件（加扣分） 步骤

  1. 在学生列表或学生档案页点击「记录事件」。
  2. 选择事件类型（德育 / 纪律 / 卫生 / 学习 / 出勤）与分值（加分 / 扣分）。
  3. 填写事件描述，可附备注。保存后立即计入操行分统计。
  4. 事件支持撤销与回滚（带审计记录），误操作可安全恢复。

使用场景 场景

开学名单入库

教务处发的 Excel 花名册直接导入，含学号与班级列，30 秒完成全班 50 人建档。

课堂即时记分

课堂上学生回答精彩 +2 分、违纪 -1 分，随手记录，期末汇总时每一分都有出处。

家长询问依据

家长质疑操行分，打开学生档案事件流，逐条展示时间、类型、分值与描述。

数据迁移备份

学期末导出学生与事件数据为 Excel，归档或导入其他班级系统。

班级管理

多班级管理、批量调班、跨班级对比分析。

使用步骤 步骤

  1. 进入「班级」页面，点击「创建班级」可添加多个班级（适合跨班任课教师 / 年级组长）。
  2. 点击班级卡片进入详情，查看班级学生、事件与学业概览。
  3. 「批量调班」：勾选多个学生，选择目标班级一键迁移，历史数据跟随保留。
  4. 「班级对比」：选择 2-4 个班级，对比操行均分、风险分布、学业指标，生成横向对比视图。
  5. 不用的班级可「归档」，数据保留但不再出现在日常视图。

使用场景 场景

年级组长巡检

管理全年级 8 个班级，用班级对比面板横向比较各班操行与风险指标，定位需要重点关注的班级。

学生转班

学生文理分科转班，批量调班一步完成，事件与成绩记录完整跟随。

学业分析

成绩录入（手动 / Excel / AI 表格识别）、考试管理与多维度分析图表。

录入成绩 步骤

  1. 进入「学业」页面，点击「新建考试」，填写考试名称（如「十月月考」）、科目与满分。
  2. 三种录入方式任选：单科录入（逐个输入分数）、Excel 导入（标准模板）、AI 录入（上传成绩单照片/表格，AI 自动识别解析）。
  3. 录入完成自动计算班级均分、排名、及格率、优秀率。
  4. 「对比分析」视图：选择两次考试，查看每个学生的进步 / 退步幅度与升降榜。
  5. 趋势图表展示单科目或总分的多考试走势，可按学生筛选。

使用场景 场景

月考后快速分析

月考成绩 Excel 直接导入，5 分钟生成班级排名与学科分析，替代手工 Excel 统计 2 小时工作。

纸成绩单数字化

只有纸质成绩单？拍照上传，AI 表格识别自动结构化，再人工校对确认。

临界生跟踪

对比分析筛选两次考试下降超 10 名的学生，结合操行数据生成重点关注名单。

学情报告

分析视图一键生成学情报告，AI 补充文字结论与教学建议，直接用于家长会。

AI 对话

与智能体自由对话，支持会话管理、上下文引用、文件上传与工具调用。

使用步骤 步骤

  1. 进入「对话」页面，点击「新建会话」。
  2. 选择对话对象：主控智能体（默认）或任一专业智能体。
  3. 输入问题或指令，AI 可自动调用 19 个工具查询班级数据（分数、排名、事件等）。
  4. 上传文件（成绩单、文档、图片），AI 结合文件内容回答。
  5. 侧栏管理历史会话，支持重命名、置顶、删除；对话内容自动保存。

使用场景 场景

随手查询

「张明这周扣了几次分？」「班级数学平均分多少？」自然语言直接问，AI 查库秒回。

写材料

「根据本班本月数据，写一段期末评语素材」「帮我起草运动会通知」，AI 结合真实数据生成。

成绩单解读

上传外班联考成绩 Excel，让 AI 对比本班数据找出差距科目。

AI 智能体

18 个专业智能体各司其职，可独立运行、定时调度或协作编排。

运行与配置 步骤

  1. 进入「智能体」页面，查看 18 个智能体卡片与状态。
  2. 点击智能体进入详情：查看职责说明、模型绑定、系统提示词（可编辑）。
  3. 「立即运行」手动触发一次，或到定时任务设置周期调度。
  4. 「运行历史」查看每次执行的输入输出、耗时与令牌消耗。
  5. 每个智能体可绑定不同模型：高频任务用快模型，深度分析用强模型，控制成本。

使用场景 场景

每周风险排查

每周一 7:00 定时运行「风险预警」，自动筛查上周数据并推送风险学生名单。

家长会前物料

依次运行「数据分析师」生成学情报告、「家校沟通」生成沟通稿，1 小时备齐全部材料。

期末综合素质评价

「周报员」按周积累的记录汇总，「辅导员」为每个学生生成期末评语初稿。

模型管理

35+ LLM 提供商统一管理：API Key、模型参数、连接测试、按智能体分配。

使用步骤 步骤

  1. 进入「模型」页面，点击「添加提供商」。
  2. 选择厂商（OpenAI / Anthropic / DeepSeek / Moonshot / 通义 / Google / Ollama 本地模型等 35+）。
  3. 填入 API Key 与 Base URL（自定义代理可改），选择默认模型。
  4. 点击「测试连接」验证连通性与可用模型列表。
  5. 在模型列表中调整参数（温度、上下文长度、最大输出），并设置各智能体绑定的模型。
  6. 多提供商可共存，按任务自动路由到性价比最优的模型。

使用场景 场景

国内直连

使用 DeepSeek / Moonshot 国内厂商，无需代理稳定访问，成本更低。

隐私零上云

配置本地 Ollama（如 qwen2.5:7b），全部 AI 推理在本机完成，数据不出设备。

成本分级

高频轻任务（记分、查询）绑定便宜快模型，周报/分析绑定旗舰模型，整体费用可控。

定时任务

Cron 表达式驱动的智能体调度与自动备份，支持漏执行补偿。

使用步骤 步骤

  1. 进入「调度」页面，点击「新建任务」。
  2. 选择任务类型：运行智能体 / 自动备份 / 自定义。
  3. 设置 Cron 表达式（如 0 7 * * 1 = 每周一 7:00），支持常用模板一键填入。
  4. 配置任务参数（如风险预警的班级范围），保存并启用。
  5. 「运行日志」查看每次执行结果；错过执行（如电脑关机）会在下次启动时自动补偿一次。
  6. 自动备份任务定期打包全部数据到本地备份目录，保留多版本。

使用场景 场景

周五自动周报

每周五 17:00 自动运行周报员，周一到校直接取用上周班级周报。

数据自动备份

每天 22:00 自动备份，即使电脑故障也能恢复到前一天的数据状态。

隐私引擎

PII 自动脱敏 / 反脱敏 / 按接收者过滤，学生敏感信息不外泄。

工作原理 原理

所有发送给外部 LLM 的内容先经过隐私引擎：姓名、身份证号、手机号、住址等 PII 被替换为 [P1]、[P2] 等占位符；LLM 返回结果后再自动还原（映射表 AES 加密存储在本地）。可按接收者（不同的模型提供商）配置不同的过滤规则。

使用步骤 步骤

  1. 进入「隐私」页面，查看脱敏规则（姓名 / 证件 / 电话 / 地址等类别）。
  2. 调整规则：对特定接收者（如某海外模型）启用更严格的全字段脱敏。
  3. 「测试面板」粘贴一段文本预览脱敏效果。
  4. 审计日志记录每次脱敏/还原操作，可追溯。

使用场景 场景

合规使用云模型

学校要求学生信息不得外传，开启严格脱敏后，云端模型只见 [P1] 未见真实姓名，回复本地自动还原。

外发材料检查

生成家长通知后用脱敏预览检查一遍，确认不含身份证号等敏感字段再发出。

飞书集成

连接飞书机器人，接收通知推送、远程查询与指令。

配置步骤 步骤

  1. 在飞书开放平台创建企业自建应用，开启机器人能力。
  2. 进入「设置」→「飞书」，填入 App ID、App Secret，点击连接测试。
  3. 配置接收人（个人 / 群组），订阅推送类型：风险预警、周报摘要、任务结果。
  4. 在飞书中 @机器人 发送指令（如「今日风险」），即可远程查询班级数据。

使用场景 场景

风险即时触达

风险预警智能体发现高危学生，飞书立即收到推送卡片，不在电脑前也能第一时间知晓。

手机上查数据

课间在飞书群里 @机器人 问「本周扣分前五名」，通勤路上也能处理班级事务。

自动更新

内置 electron-updater，新版本发布后应用内直接升级，安装包带 SHA512 校验。

使用步骤 步骤

  1. 应用启动时自动检查更新；也可在「设置」→「关于」点击「检查更新」。
  2. 发现新版本后点击「下载」，进度条实时显示。
  3. 下载完成（已通过 SHA512 校验）后点击「重启安装」，应用自动完成升级。
  4. 更新源支持 GitHub Releases 与 Gitee 镜像，国内网络可在设置中切换 Gitee 源加速。

使用场景 场景

无感升级

教师无需手动下载安装包，新功能与修复直接推送，始终使用最新稳定版。

安全可靠

差量更新（blockmap）只下载变化部分，且每一步校验文件哈希，杜绝被篡改的安装包。
