## 完整旁白稿 v2（约 380 字 / 78s 配音）

晚上十一点，办公桌前还亮着灯。一摞记录本，三个未回的家长群，一份明早要交的周报。
在中国，每一位高中班主任，每周要花八到十二个小时，埋在表格、记录、家校沟通里。
Education Advisor，是一台桌面端的教育操作系统，让十八个 Agent 替你分担。
打开应用，在对话里输入一句话：Alice，作业，加两分。Class Monitor Agent 立刻解析成结构化事件，写入本地事件库。
点开仪表盘，柱状图、趋势线、风险分布实时呈现，每一条数据都可追溯到原始事件。
隐私面板里，所有学生姓名在送往大模型之前，先被替换成 S_017 这样的编号；每一次调用，都记录在审计日志里，AES-256 加密，永不可篡改。
清晨，晨检摘要推到你手机；上午，一键出具本周班级数据；中午，给家长发一条有理有据的提醒；晚上，所有数据加密归档。
Rust 引擎只写不改，每一条事件都带时间戳和哈希，永久可回溯。
数据留在你手里，判断由你做主，AI 只是副驾。
Education Advisor，让老师回到讲台。

## 制作备注

- 配音语速：约 4.3 字/秒（沉稳风格）
- 配乐：轻钢琴 ambient，80s，淡入 0-3s，淡出 75-80s
- 场景图 prompt 全部用半写实电影感关键词统一：cinematic, soft warm light, shallow depth of field, 16:9, 2K
- Ken Burns 动效：1.00 → 1.05（5% 推拉，从 18% 降低到 5%），缓动 ease-in-out
- S3/S4/S5 用真实 app UI 渲染（深色模式 + ECharts + glassmorphism）
