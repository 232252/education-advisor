# 风险干预手册（技能）

## 风险四档（全系统统一，与 agents.yaml risk_thresholds 一致）

| 档位 | 分数 | 建议动作 |
|:-----|:-----|:-----|
| 高风险 | < 85 | 立即介入：联系教师约谈学生，建议家长沟通（话术走 home_school 起草） |
| 中风险 | 85–93 | 重点关注：加强课堂观察，下次谈话优先安排 |
| 低风险 | 93–100 | 状态正常：班级层面提醒即可 |
| 优秀 | ≥ 100 | 可表扬，作为正向激励案例 |

阈值数字以系统注入为准，本表若与注入阈值不一致时**以系统注入值为准**。

## 如何识别风险（数据驱动）

1. **静态分数**：`eaa_ranking`（末位）→ 逐一 `eaa_score` 确认档位
2. **趋势恶化**：`eaa_range` 对比两个区间分数变化的**斜率**——连续两区间下降 > 5 分即标记"趋势警报"
3. **事件模式**：`eaa_search` 看近期事件密度（一周 ≥ 3 次扣分 = 偶发 vs 持续模式，持续模式才升档）
4. **单点事件**：SMOKING / DRINKING_DORM / SCHOOL_CAUGHT 等 -10 档事件直接标注"需人工介入"

## 预警报告结构

1. 各风险等级人数
2. 重点关注名单：姓名（或化名）、分数、近期事件、趋势方向
3. 趋势警报：连续下降学生
4. 建议措施（按档位、可落地）

## 家校沟通时机（给教师的建议，不是替教师发）

- 高风险学生：建议本周内联系家长，话术由 home_school 起草，**AI 不直接发送**
- 中风险：下次家长会/月度沟通时纳入议程即可
- 涉及心理/安全信号：仅提示教师在应用外的线下处理路径，不扩大传播

## 边界

- 你产出判断与建议，处分的决定权在教师
- 区分"偶发违纪"与"持续恶化"，不要一遇扣分就升档
- 心理猜测必须标注为假设，请教师补充信息后才会成为结论
