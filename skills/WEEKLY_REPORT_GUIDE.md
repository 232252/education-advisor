# 周报撰写手册（技能）

## 触发与周期

- 默认周期：**本周一到当前日期**；按教师要求可指定任意日期范围
- 对比基准：**上一个同等长度周期**（上周一至今 vs 上周同期），变化标注 ↑/↓
- 日期必须是 `get_current_time` 确认后的真实日期，不要猜测

## 数据来源组合

| 需求 | 工具 |
|:-----|:-----|
| 本周总览分数分布 | `eaa_stats` / `eaa_summary`（带范围参数） |
| 逐学生变化 | `eaa_range`（时间区间汇总，与上一周期同范围对比；退步名单 = 两个 `eaa_range` 结果对比，`eaa_ranking` 只反映当前快照、无法查历史周期） |
| 排行榜（当前快照） | `eaa_ranking`（分数从高到低，找低分学生传大 n 看末尾） |
| 重点事件 | `eaa_search`（按周范围 + 关键词） |
| 原因码分布 | `eaa_codes`（行内解释给教师用） |

所有数字必须来自工具输出，**禁止心算汇总**（如"从上周 87 到本周 90"必须从两次工具结果取数）。

## 周报结构模板

1. **本周概况**：平均分、风险人数、事件总量（对比上周）
2. **重点关注**：风险名单（分数、近期事件、趋势方向）
3. **事件分析**：本周扣分/加分 Top 原因码，结合班级管理背景解读
4. **进步与亮点**：进步显著学生、可表扬的正向事件
5. **建议措施**：每条建议必须对应数据依据，可落地（如"周三班会强调迟到，近两周迟到 -2 事件 7 起"）

## 输出与落盘

- 产出一份 markdown 周报，命名 `weekly_report_<起>_<止>.md`
- 写入 `data_archive/agent_outputs/`（用 write_file，系统文件工具）
- 报告是给教师看的**成品**：指出 "AI 已生成"；若教师要求在应用内查看，引导其在报告中心查看

## 常见坑

- 多名学生重名：用名单/学号维度区分，不要凭印象合并
- 期初无对比数据：如实说明"无上一周期基线"，不要编造对比
- 大范围点名：教师才是处置者，报告只提供名单和依据，不替教师下结论
