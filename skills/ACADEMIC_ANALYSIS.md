# 考试成绩分析手册（技能）

## 何时用本技能

教师问「这次考试怎么样」「谁退步了」「单科哪些人要补」「把成绩和操行放一起看看」时。
成绩数据由教师在「学业」页录入；你只能查询（eaa_exams / eaa_exam_grades / eaa_student_grades 只读），
**没有录入或修改成绩的工具**——缺数据时引导教师去学业页录入，不要自己编。

## 标准工作流

1. **先拿考试清单**：`eaa_exams`（可按学期过滤）→ 拿到考试 ID、科目构成、各科满分。
2. **全班分析**：`eaa_exam_grades(exam_id)` → 每科统计（人数/均分/最高/最低/缺考）+ 学生得分表。
3. **单生诊断**：`eaa_student_grades(name)` → 该生历次考试时间线（按日期倒序），判断趋势。
4. **关联操行**：配 `eaa_stats` / `eaa_summary` 看同期操行表现，输出「成绩+行为」双面结论。

## 计算口径

- **六科加权（高考口径）**：语文/数学/英语权重 1.5，物理/化学/生物权重 1.0。
  加权分 = Σ(科目分 × 权重)。多步计算用 `calculate` 工具，不要口算。
- **分数段（单科）**：≥90 优秀｜75–89 良好｜60–74 中等｜50–59 及格边缘｜<50 不及格（需干预）。
- **跨科目比较**：各科满分不同（主科 150 / 理综 100），**不能直接比原始分**；
  先换算成得分率（分数 ÷ 满分）再比较。

## 常见坑

- `score: null` 是**缺考**；某科目在学生记录里**没出现**是**未录入**——两者含义不同，报告里要分开说。
- 「退步」要看至少两次考试的相对变化（eaa_student_grades 时间线），单次波动不下结论。
- 满分差异 + 加权口径必须在报告开头声明，否则教师会误读数字。
- 成绩与操行分是两套独立数据（考试 vs 行为事件），分析时明确标注数据来源，不要互相推断。
- scope 标记 `ai-grading` 的考试来自「批改作业」页发布（科目形如「1.选择题/总分」）——
  逐题依据与批改过程见 AI_GRADING 技能（eaa_grading_* 工具），两套口径不要混表比较。

## 输出建议

- 全班报告：结论先行（X 人需关注）→ 每科概况表 → 名单（附得分率与排名变化）→ 干预建议。
- 单生报告：趋势线描述（哪科稳/哪科滑）→ 与操行事件的关联 → 给教师的具体动作建议。
- 产物落盘：`data_archive/agent_outputs/`（write_file，Markdown），命名含考试名与日期。
