# AI 批改作业（Grading）— 功能指南

内置的 AI 批改子系统：教师在本机完成「建任务 → 传试卷 → AI 按量规批改 →
教师复核 → 发布进学业分析」的完整闭环。侧边栏一级入口「批改作业」。

> 数据模型与批改流程以开源项目 [Submitty](https://github.com/Submitty/Submitty)
> 的改卷链路为蓝本（量规 → 逐题给分 → 教师覆盖 → 发布），上游 schema 以
> `vendor/submitty/` 参照面形式内置并随上游月度发版更新（见
> `vendor/submitty/README.md`）。

## 使用流程

1. **新建任务**（侧边栏 → 批改作业 → + 新建任务）
   - 填任务名/学期/日期/班级/科目；在量规编辑器里录入每道题的
     **题号、满分、参考答案或评分标准**（这是 AI 的判分依据，越具体越准）；
     每题可加 **评分点**（Submitty marks：从满分加减的扣分/加分项，如「漏写单位 -2」），
     复核时点选即改分；
   - **量规不用手敲**：点「从样卷识别」选 1~8 张样卷照片（含答案页更佳），
     AI 自动抽出题目、满分与参考答案草稿，教师只需校对（见下节）。
2. **导入试卷并归组**
   - 支持批量多选 jpg/png/webp/bmp（PDF 请先转为图片）；
   - **同名多页自动合成一份**（`张三_1.jpg` + `张三_2.jpg`，或「第 N 页」/ `p1`）；
     相机流水号（`IMG_001`）不会误合成。也可点「导入为同一份」强制把当前所选当作一学生的多页卷；
   - **文件名不必改**：卷面写上姓名或编号后，点「从卷面识别」或直接「开始 AI 批改」——视觉模型读首页，与班级名单唯一对上才自动归组；认不出的留给下拉框人工指认；
   - 文件名含学生姓名时仍会给归属建议（唯一命中才建议）。
3. **标记就绪 → 开始 AI 批改**
   - 逐份串行批改，实时进度条；可随时中止，已完成的结果保留；
   - 失败的试卷（网络/模型原因）可单独「重试失败试卷」。
4. **复核**（双栏工作台：左原图、右逐题给分）
   - 每题可见 AI 得分与判分依据；教师可改分/写评语（改分优先于 AI 分）；
   - 有评分点时点选即从满分加减合成该题分数（与 Submitty TA 点 mark 同一口径）；
   - 总评 + 生效总分实时合成；上一份/下一份快速切换。
5. **导出批阅痕迹**
   - 任务详情或复核台点「导出批阅痕迹」：把原卷扫描件叠上红框批注、逐题得分与评语，
     排成可打印文档；打印对话框中选「另存为 PDF」或直接送到打印机；
   - 整班一次导出（每生自动分页），也可在试卷行/复核台只导出当前一份。
6. **发布成绩**
   - 任务 → 一场考试（scope 标记 `ai-grading`），每道题 → 一个科目（如「1.选择题」），
     另加「总分」科目；写入既有学业管线，**考试分析/学生档案/报告中心/Agent 全链路自动可见**；
   - 重复发布幂等（同一考试覆盖更新）；已发布后仍可打开复核改分，点「重新发布」覆盖原考试；
   - 未归组/未批改/分数不完整的试卷会列入跳过清单。

## 从样卷识别量规

量规编辑器（新建任务弹窗 / 任务详情）中的「从样卷识别」：把纸质样卷拍几张
照片（1~8 张，jpg/png/webp/bmp，单张 ≤25MB），AI 视觉模型自动生成量规草稿。

- **拆题粒度**：按卷面最高层级题号拆（「一、二、三」或「1、2、3」），
  选择题这类大题合并为一条，小题明细并入题名/参考答案；需要更细可手动拆分；
- **参考答案**：照片里有答案页/评分标准则照录；没有则 AI 自行给出答题要点
  草稿，尾部带「（AI 草稿，请核对后删此标注）」——发布批改前记得核对删除；
- **无状态**：样卷照片只读不保存，识别结果不落盘，覆盖前会二次确认；
- 使用**批改模型**（设置 → 模型 → 批改模型），须为支持图像输入的视觉模型。

## 从卷面识别归属（不必改文件名）

扫描件可以继续叫 `IMG_001.jpg`。系统看的是**首页页眉/姓名栏**上的字，不是文件名。

- **写姓名（推荐）**：首页写清楚与班级名单一致的姓名。点「从卷面识别」，或标记就绪后直接「开始 AI 批改」（会先识别未归组的卷）。唯一对上才自动归组，再进入批改。
- **写编号**：编号必须能对上该生在名单里的内部编号、分组或角色。系统**没有单独的学号/座号字段**——卷上写「12」而档案里没这个编号，对不上，留给下拉框手选。
- **不猜**：字迹不清、空白、同名（张三 / 张三丰）一律保持未归组，请人工指认。
- **每生一份**：自动归组时，该生名下已有试卷则跳过第二份；发布成绩时后一份不会覆盖前一份（记入 skipped）。人工改派仍可指到同一学生，请自行确认不是重复扫描。
- **多页**：`张三_1` / `张三_2` 会合成一份；相机流水号 `IMG_001` / `IMG_002` 不会自动合成，请用「导入为同一份」。
- 须配置**视觉模型**（设置 → 模型 → 批改模型）。

## 批改模型

- 设置入口：**设置 → 模型 → 批改模型**（也可从批改页错误提示跳转）；
- 只列出**支持图像输入**的视觉模型；未选择时跟随「高质量模型」（若该模型不支持
  看图，启动批改会明确报错）；
- API Key 复用各 Provider 的既有配置（Keystore 加密存储）。

## 与其他子系统的联动

| 面 | 说明 |
| --- | --- |
| 学业分析 | 发布后 `eaa_exams` / `eaa_exam_grades` / `eaa_student_grades` 可查 |
| 对话/Agent | `eaa_grading_overview` / `eaa_grading_student` 两个只读工具（`academics` 能力），配 `skills/AI_GRADING.md` 技能；隐私脱敏自动包裹 |
| 备份/恢复 | `<数据目录>/grading/`（任务 JSON + 试卷扫描件）随全量备份 |

## 数据与存储

- 任务 JSON：`<appData>/grading/tasks/<taskId>.json`
- 试卷扫描件：`<appData>/grading/files/<taskId>/`
- 状态机：草稿 → 已就绪 → 批改中 → 待复核 → 已发布（已发布可回流复核改分再发布；详情页「重新发布」直接覆盖）

## 常见问题

- **AI 批改失败**：看试卷行的错误提示（悬停）；常见为模型不支持图像、API Key
  失效、网络超时；处理后点「重试失败试卷」。
- **归组建议不出现**：检查文件名是否含学生完整姓名；或卷面姓名是否写在首页页眉。
  歧义命中（如「张三/张三丰」）一律留给人工指认。编号须能对上名单里的学号/编号别名。
- **想改量规**：仅草稿/已就绪态可改；已有批改结果后量规锁定（保证逐题结果
  始终对应一套稳定量规），需要时请新建任务。
- **评分点怎么用**：每题可加若干「从满分加减」的项（如漏写单位 -2）。复核时点选
  即合成该题分数；AI 批改也会按评分点给 `marks`。分值可正可负，结果钳制在 [0, 满分]。
- **如何打印批阅痕迹**：任务详情、试卷行或复核台点「导出批阅痕迹」，预览后在打印
  对话框选打印机或「另存为 PDF」。红框叠在原卷扫描件上，便于发给学生或归档。
- **从样卷识别的粒度/分值不对**：识别按卷面大题拆条，小题不单独拆；分值
  按卷面标注，无标注时为估计值——识别结果只是草稿，发布批改前请逐题核对。
