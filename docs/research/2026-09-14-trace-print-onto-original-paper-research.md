# 调研报告：痕迹回写原件打印（红痕打回学生原卷）

> 日期：2026-09-14 ｜ 性质：**只调研 + 给方案，不改代码**（本轮明确约束"这一次不改代码"）
> 背景：现行"痕迹卷"打印（4d8ca52 装机版）是把**扫描照片整页再打一遍**，用户认为没有必要——原件就在手里。真实需求是：收卷→拍照/扫描→AI 批改出痕迹→**把学生写过的原卷放回打印机→打印机把红痕（每题得分、总分、批注）打在原卷对应位置上**，底图不出墨。照片有倾斜/扭曲/拉伸，要求利用 4 个定位点把坐标"拉正"；本地没能力就让 AI 识别定位点。
> 结论先行：**几何上完全可行，缺的是"扫描图坐标系 → 打印机 A4 坐标系"的换算层（单应变换）和基准点检测，两者目前代码里都是零**；输出层两条路线都已验证有现成能力（渲染层 CSS 毫米定位打印 / 主进程 napi-rs/canvas 直接生成精确 A4 PDF）。

---

## 0. 速览结论

1. **用户的诉求在数学上就是一次透视变换（单应变换）**。平面纸张拍成照片 ≈ 平面射影变换：找到扫描图上 4 个基准点（定位点或纸角）及其在 A4 原卷上的物理位置，即可解出 8 自由度矩阵 H，把任意痕迹坐标从"照片坐标系"换算到"打印纸毫米坐标"。"根据 4 个定位点拉伸"不需要真的拉伸图片——**打回原件只印红痕，根本不出底图，只需要映射"点坐标"**；若想让屏幕复核/AI 看到正过的卷面，用同一个 H 反向重采样即可（锦上添花，非必需）。
2. **现状缺口三块**（`grep` 全库确认"定位点/anchor/homography/透视/矫正"零命中）：
   - 无基准点检测（定位点■ / 纸张四角都无实现）；
   - 无坐标换算（AI 的 `box` 只存在于"这张照片"的 0–1 归一化坐标系里，换算不到打印纸毫米）；
   - 无"无底图红痕版式"（现在的痕迹卷 = 照片 84% 宽 + 右侧批注栏，天然带着底图）。
3. **基准点要分两级看**：
   - 自印物理试卷通常**没有印刷定位点**，最通用的基准是**纸张四个角**（照片里白纸对深色背景的二值化 + 最大四边形；扫描仪图则纸边≈图边）。四个角对应的物理位置就是 A4 的 (0,0)–(210,297)，**无需任何模板知识，今天的数据就能用**。
   - 答题卡式**实心黑方块定位点■**检测精度更高（形状/对比度先验强），但要有人告诉系统"方块在原卷的哪几毫米处"→ 需要"母版标定"（一次）。P2 做；P3 甚至可以**反向输出带定位点的印制版母版**，让以后的考试卷天生可回写。
4. **AI 检测兜底可行且便宜**：视觉模型返回四点粗坐标（±10–30px），本地 CV 在小窗口内做暗质心/角点精修。本项目 `completeSimple` + 严格 JSON 的视觉调用模式现成（`identify-papers.ts`），照抄即可。三级策略：**本地 CV（免费/确定性）→ AI 粗定位 + CV 精修 → 人工四点拖拽校正**（最后一级必须存在，是所有网评系统的标配逃生门）。
5. **精度要有正确预期**：V1（角点 + 逐卷 AI box）误差典型 ±5–10mm、最差 ±10–25mm——够"分数打在题目旁边"，密集排版可能蹭到相邻题；V2（母版标定，全班痕迹位统一）误差收敛到 ±3–6mm（含打印机回纸歪斜），达到商用网评回写水平。**误差大头不是几何，是 AI 每题 box 的逐卷抖动**——这是 P2 母版标定值得做的原因。
6. **输出路线已验证**（本文档写作时实测）：
   - 渲染层：现有 `PrintOverlay` + CSS `mm` 定位即可排版"只有红痕的 A4 页"，霞鹜文楷字体链路现成（痕迹卷打印已在用），走系统打印对话框（需用户选"实际大小 100%"）；
   - 主进程：`@napi-rs/canvas`（已在依赖、已在用）的 `PDFDocument.beginPage(595.28, 841.89)` 实测产出**精确 A4 MediaBox 的 PDF**，1mm=2.8346pt，可毫米级放红字，适合存档/批量/静默打印（Electron 43 的 `webContents.print({silent, pageSize:'A4', margins:none})` 可绕过对话框缩放风险）。
7. **打印机物理现实必须写进产品**：回纸歪斜 0.5–1.5°（远端漂 3–6mm）、硬件不可打印边距 3–5mm、驱动默认"适合页面"缩放是最大杀手（必须 100%）、双面卷翻面坐标 V1 先不做。所以 V1 必须带**试打一张 + 全局 dx/dy 微调**，这是所有回写类产品的标准动作。

## 一、用户需求还原（物理工作流）

```
收上来的答题卡/试卷 → 拍照或扫描导入 → AI 批改(已有) → 复核(已有)
        ↓
把学生写过的原卷放回打印机进纸口
        ↓
打印"红痕覆盖页"(无底图: 每题得分 ✓/✗/12分 + 总分 + 批注)
        ↓
红痕必须落在这份原卷的对应题目位置上 ← 全部难点在这里
```

用户明确的三要素：**每题分数、总分、批注**，都要"打在题目上"，而不是重打一遍照片。拍照来源的图有透视扭曲/拉伸，需要按 4 个定位点换算。

### 2.2 坐标系现状（关键）

- AI 每题返回 `box: {page, x, y, w, h}`，**0–1 归一化、相对该页扫描图**（`src/shared/types/grading.ts:54-62`；prompt 要求 `grading-pipeline.ts:132-133`；解析钳制 `grading-pipeline.ts:237-249`）。

- 样卷（原卷）只用于抽量规，**用完即弃不留档**（`batch-from-files.ts:117-124` 临时目录；`rubric-extract.ts:4` 注释"只读不拷贝"；UI 路径 `RubricEditor.tsx:110` 同样无状态）→ 母版标定（P2）需要先补"样卷留档"。

## 三、几何原理（为什么 4 个点就够）

平面纸张在针孔相机模型下，物面→像面是**射影变换**（含旋转、平移、缩放、剪切、透视/近大远小，共 8 自由度）。4 对不共线的对应点唯一确定 3×3 单应矩阵 H（DLT 解法，纯函数 ~60 行）：

```
扫描图像素 (u,v) --H--> A4 毫米 (x,y)

  s·[x,y,1]ᵀ = H · [u,v,1]ᵀ
```

- 照片歪了/斜了/一头远一头近 → H 一次性吃掉，**这就是"根据 4 个定位点拉伸"的数学本质**；
- 回写打印只需要映射**点坐标**（把每题痕迹的落点从照片坐标换算成毫米），不需要真的重采样图片；
- 若要给复核台/AI 看"正过的卷面"，用 H⁻¹ 对像素做逆向双线性重采样（napi-rs canvas：三角剖分仿射两遍或 JS 逐像素，300dpi A4 单页 1–3s，一次性成本）——属于增值项，不是回写的前提；
- 4 点的**检测精度**直接决定 H 质量：定位点■（高对比、已知形状、子像素质心）优于纸角（边缘虚、背景干扰）；所以"有定位点用定位点，没有用纸角 + 人工校正兜底"。

## 四、方案设计

### 4.1 总体架构（新增"回写"数据流，虚线为新增）

```
扫描件(存档原图) ──┬── 基准点检测: ①本地CV(纸角/定位点■) → ②AI粗定位+CV精修 → ③人工四点校正
                  │        ↓ 四点像素坐标 + 对应A4物理位置(mm)
                  │   单应矩阵 H (shared 纯函数, 单测覆盖)
每题痕迹(现有 paperMarkOverlays 的 box+mark+note)
                  │        ↓ box×图像尺寸=像素 → H → A4 mm
                  │   回写版式数据(每痕: mm坐标+文字+字号)
                  │        ↓
                  │   输出: A) 渲染层 PrintOverlay 新模式「回写原件」(CSS mm, 字体现成)
                  │        B) 主进程 PDFDocument 生成回写 PDF(精确A4, 可存档/批量/静默打印)
                  └── 预览: 红痕叠在扫描图上(半透明)供确认 + 试打微调(dx/dy)
```

### 4.2 基准点三级策略（回答"有没有能力 / AI 识别"）

| 级别 | 做法 | 适用 | 精度贡献 |
|---|---|---|---|
| ① 本地 CV | **纸角**：灰度→自适应阈值（白纸/背景分离）→最大连通域→边界四极值点/最小外接四边形；**定位点■**：阈值→连通域→面积/长宽比/实心度/暗度筛选→四象限各取最优 | 手机拍整页、扫描仪图、带■的答题卡 | 纸角 ±1–2% 页面（3–6mm）；■ ±0.5–1%（1.5–3mm） |
| ② AI 兜底 | 视觉模型返回 4 点粗坐标（prompt 同 identify 风格，输出 JSON 像素坐标）→ 以 AI 点为窗心做 CV 精修（窗口内暗质心） | 背景杂乱/纸角不可靠/■样式特殊 | 视精修质量，通常回到 ① 水平 |
| ③ 人工校正 | 复核台/导出向导里的四点拖拽 UI（默认预填①或②结果） | ①②都失败的少数卷；也是首启信任建立手段 | 人眼对齐，≈①水平 |

检测在**主进程**做（napi-rs canvas + AI key 都在主进程；渲染层只拿结果和预览图）。检测结果**落库到任务 JSON**（每份卷每页：`quad: {tl,tr,br,bl}` 像素坐标 + 来源标记 + 置信度），复核台可回显重校。

### 4.3 痕迹落点：两档精度路线

| 档 | 落点来源 | 精度 | 成本 |
|---|---|---|---|
| **V1：逐卷 AI box** | 现有 `GradeAnnotationBox`（AI 批改时返回）经 H 映射 | ±5–10mm 典型（box 抖动主导，逐卷位置不一致） | 零新增流程，改造成本最低 |
| **V2：母版标定**（推荐演进） | 样卷留档 → AI 在**干净样卷**上一次性标出每题作答区（可顺带复用量规抽取的调用）→ 全班统一痕迹位；学生卷只负责解 H | ±3–6mm（几何残差+打印机），全班痕迹位完全一致，与商用网评回写同构 | 需"样卷留档 + 模板定位"两个新环节 |

V2 的关键认知：**误差大头是 AI 每题 box 的逐卷抖动，不是几何**。学生的作答位置由试卷模板决定、不由照片决定——在母版上标一次，比在 50 张照片上各标一次又准又稳。

### 4.4 回写版式（打在原卷上的内容）

沿用现有红笔口径（`paperMarkOverlays`：全对✓ / 零分✗ / 部分对"12/28"），新增：

- **每题短痕**：落作答区右上角外侧（现有 `markStyle` 策略平移到 mm 空间）；
- **总分**：固定落首页右上（或页眉得分框位置，母版标定后可自定义）；`86/100` 红字；
- **批注**：主观题评语沿题目 y 位置排在**页右边距**（自印试卷一般有 10–15mm 右边距，7–8pt 手写体红字，`layoutMarginNotes` 逻辑改为 mm 空间）；边距放不下时降级为短标记+完整批注进批阅报告（用户可选）；
- **不出底图、不画红框、无页眉**；卷尾防混卷小字改为可选（默认关——它本身也是一种"落点"，可能压到原卷内容）。

### 4.5 输出与打印路线

| 路线 | 实现 | 优点 | 风险/代价 |
|---|---|---|---|
| **A. 渲染层打印（V1 主路线）** | PrintOverlay 新增第三模式「回写原件」：A4 页面容器（210×297mm、`@page margin:0` 覆盖），红痕用 CSS `mm` 绝对定位 | 字体（霞鹜文楷）现成、预览即打印、复用全部现有打印设施、改动最小 | 走系统打印对话框：**必须引导用户选"实际大小/100%、A4、关适合页面"**（对话框里给显眼提示） |
| B. 主进程回写 PDF（P2） | napi-rs `PDFDocument` 每页 595.28×841.89pt，红痕按 pt 放置（实测可行）；`showSaveDialog` 存档/`shell.openPath` 唤起系统打印 | 几何与驱动解耦的**可存档工件**；支持"逐份一档"；字体子集化需处理（系统楷体实测可渲染但整字嵌入 ~6.5MB，需评估子集或降级 sans） |
| C. 静默连打（P3） | Electron 43 `webContents.print({ silent:true, pageSize:'A4', margins:{marginType:'none'}, printBackground:true, deviceName })` | 全班连打免 50 次对话框；打印参数代码写死，**根除"适合页面"缩放风险** | 需隐藏窗口承载版式；进纸顺序=打印顺序的操作纪律 |

三条不冲突：A 先上，B/C 是渐进替换输出端。

### 4.6 操作流（产品设计，V1）

```
批阅痕迹按钮 → 模式切「回写原件」
  → 逐份跑基准点检测(进度条;失败卷列表可人工四点校正)
  → 预览: 扫描图半透明垫底 + 红痕实位(所见即所得)
  → [试打一份]: 对话框强提示"实际大小/100%/A4" → 打出来对位
  → 不准? 全局微调 dx/dy(±mm 步进) 再试
  → [全班打印]: 按名单排序逐份出页, 提示"按屏幕顺序放卷, 先试 3 份"
```

不做：双面、批量静默、模板标定、卷面矫正图。

### P2 — 母版标定 + 印刷定位点（精度跃升）

- 样卷留档：`RubricEditor` 从样卷识别时把样卷页**拷贝进任务目录**（`templatePages`），UI 导入与 `batch-from-files` 两路都留。
- 模板定位：AI 在干净样卷上一次调用标出每题作答区（题号 ↔ 量规 id 对齐；顺带可校 AI 抽量规的题序）；痕迹位全班统一。
- 定位点■检测接入（有■的答题卡自动优先用■）；母版标定 UI：在样卷图上确认四点（或 PDF 页面直接读■位置）。
- 回写 PDF 产物（路线 B）：napi-rs PDFDocument，逐份存档可选。
- 卷面矫正图（增值）：导入或批改前用 H⁻¹ 出正卷，AI 看图更正、复核台更直——与回写共用同一 H，边际成本低。

### P3 — 批量与生态

- 静默连打（路线 C）+ 打印队列（缺纸/卡纸续打）；
- 双面卷：翻面后 H 独立（每页各自检测），进纸方向提示；
- **带定位点印制版**：从样卷 PDF 重新输出加■母版（右下角同屏加考生条码区），以后考试卷天生可精准回写——把"事后补救"变成"事前布点"；
- 检测不稳时评估 opencv.js 替换自写 CV。

## 六、风险与现实边界（必须向用户交底的）

| 风险 | 量级 | 缓解 |
