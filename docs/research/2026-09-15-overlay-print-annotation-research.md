# 调研报告：普通打印机套打批注（痕迹打印·粗口径）

> 日期：2026-09-15 ｜ 性质：**只调研 + 给方案，不改代码**（用户第 9 点明确约束）
> 本轮口径由用户给定（见 §一）：普通打印机**套打**——粗批注可做、精细圈画不做；**要有批注（不一定要圈写）、要有总分、要有边界、任意试卷答题卡都能用、带定位点的答题卡要加强利用定位点**。
> 与 09-14《痕迹回写原件打印》的关系：09-14 解决的是**几何层**（扫描图坐标 → A4 毫米的单应换算 + 基准点三级检测）；本轮在其上补齐**内容与版式规范层**（套打打什么、打在哪、边界怎么留、精度分级到什么内容能打），两者合起来才是完整的套打方案。P1/P2/P3 分期在 §五做了修订合并。

## 0. 速览结论

1. **内容层今天就已就绪**：`paperMarkOverlays`（`grading-helpers.ts:255`）产出的正是"粗批注"口径——每题 ✓/✗/得分短痕贴作答区角外 + 主观题页边批注（含扣分说明，160 字上限）+ `effectiveTotalScore` 总分。**"套打要有批注、不一定要圈写"与现有设计完全一致**（红框仅屏幕复核用、打印不画，永不压学生字迹）——套打不需要新内容策略，只差把它从"打在照片上"换成"打在 mm 坐标上"。
2. **缺的仍然是三层**（09-14 结论复核后依然成立，09-15 三档批改未触及）：几何换算层（全库零实现）、**无底图套打版式**（现在的痕迹卷 = 照片 84% 宽 + 右侧批注栏，天然带底图且缩放）、**校准机制**（无 100% 引导、无试打、无 dx/dy/scale 微调、无打印机档案）。
3. **商用方案全部收敛到同一架构**（6 件专利 + 灌顶云/讯飞/极课，§三.1）：模板对位 → 生成批注**图层** → **人工微调**（商用专利把"用户在界面上手动调整"写进了流程）→ 驱动打印机把图层套回原卷。普通打印机方案与商用一体机的差距主要在硬件（专用纸路+扫描头同轴+压平机构），**不在软件架构**——软件侧我们照抄这个架构即可。
4. **任意性与定位点是两条并行轨道，商用也是双轨**（CN111415282A 明确"答题卡形式"与"非答题卡形式"两条链路）：
   - 任意卷：纸角检测兜底（零模板知识）→ 无定位点模板配准（CN111626280B 同构，预期位置匹配）→ 人工四点（逃生门）；
   - 答题卡：四角定位点■（OMR 行业标准，机读卡印刷规范）→ 单应更稳，还能利用**题目框/得分栏**这些印刷结构。
5. **边界要做成"预算表"而不是一句口号**（§四.3）：硬件不可打印边距 3–5mm ＋ 套印容差 ±0.5–2mm ＋ 回纸歪斜 0.5–1.5°（页远端漂 3–6mm）＋ 几何残差（V1 ±5–10mm / V2 ±3–6mm）——四项叠加决定了"页边 8–10mm 内不落痕、落点必须偏了也不坏（题号右侧/角外/页边）"；字号走**层级体系**（批注小字六号级、题分中、总分级大，§4.2.1），不设硬性下限。
6. **纸张规格档案是被 09-14 方案漏掉的通用性缺口**：中国学校试卷大量是 8K（≈270×390mm）/16K（≈195×270mm），答题卡还有 64K（≈95×65mm）——商用专利明确支持 A3/A4/8K/16K。套打版式不能写死 A4，需要"纸张规格档案"（尺寸 + 宽高比自动识别 + @page 尺寸联动）。
7. **缩放是唯一"一票否决"项**：驱动默认"适合页面"（缩放 96–99%）会让整页错位几十 mm；社区一致口径（PrintTiler/Rasterbator/PrintReadyKit）：100% 实际大小、关适应页面、关无边框、**打印含 100mm 标尺的校准页用尺子实测验证**——即使设了 100% 仍可能有 1–2% 缩放（Affinity 论坛实测案例），所以校准页必须打。
8. 用户贴文最后一句"精细圈画别套打，改打合并 PDF"——**我们已经有这条路**：现行痕迹卷（照片+痕迹合并输出）保留为"精细模式"，套打作为新档"回写原件"并列，两档共存不互斥。

| 手写体红字 | `handwriting-mark` 类（霞鹜文楷） | 渲染层打印字体现成（09-14 已验证） |

### 2.2 输出层（现形态 = "合并打印"，不是套打）

- 痕迹卷 paper 模式：**扫描照片整页 84% 宽** + 右侧 16% 批注栏（`GradingMarksDocument.tsx:46-74`、`PaperScanPages.tsx:107`）——是"批过的原卷的复制品"，既非套打、也非 1:1。
- 打印链路：`window.print()` 系统对话框（`PrintOverlay.tsx:61`），`@page margin:12mm`（`globals.css:399`），paper 模式用 `!px-2` 压边——**无"实际大小 100%"引导、无纸张规格选择、无 dx/dy 微调**。
- 主进程 PDF 生成：零（`@napi-rs/canvas` PDFDocument 能力 09-14 实测可行但未使用）；静默打印：零（Electron 43 支持，未接线）。

### 2.3 几何层（零实现，09-14 结论不变）

- AI `box`（`GradeAnnotationBox`，`types/grading.ts:71-78`）为 0–1 归一化、只活在"该张照片"坐标系；staged-pipeline 的版面定位（`staged-pipeline.ts:350-394`）输出同一坐标系，**同样换算不到打印纸毫米**。
- 全库 grep 复核（09-15）：单应/仿射/定位点/registration 仍零命中。
- 基准点（纸角/■/人工四点）检测：零。

**结论：套打 = 内容层(有) × 几何层(缺) × 无底图 mm 版式(缺) × 校准机制(缺)**。后三者即 09-14 P1 的主体，本轮再往上叠"内容规范 + 边界模型 + 精度分级"。

### 3.2 答题卡定位点规范与检测（用户第 7 点的行业依据）

- [机读卡印刷标准](http://www.hbwenhan.com/dynamic/1908.html)：定位点 = **四角黑色实心方块**，是机器阅卷的"眼睛"和"尺子"——定位纠偏（找方向/倾斜/偏移，建立整页坐标系）。OMR 术语里页面两侧成排的黑方块叫**时钟点/同步头**（逐行同步）。[百度百科·答题卡](https://baike.baidu.com/item/答题卡/7470970)：常规尺寸含正 64K 95×65mm、大 64K 105mm 等；**纸张涨缩与印刷裁切精度**本身就是官方承认的定位误差源（套打别指望完美）。
- 检测算法成熟（[OpenCV 答题卡识别·知乎](https://zhuanlan.zhihu.com/p/668870350)、[Hough 倾斜校正](https://developer.aliyun.com/article/981973)、[GitHub 开源实现](https://github.com/violin0847/AnsSheetRecognize)）：灰度化→阈值→轮廓→四角黑块质心→**透视校正**。09-14 方案"阈值+连通域+面积/长宽比/实心度筛选，自写 200–300 行"的判断与这些公开实现的工作量一致，不需要引 OpenCV。
- [CN111626280B 无定位点答题卡识别](https://patents.google.com/patent/CN111626280B/zh)：**模板文件含各关键区域预期位置**，图像与模板配准，无需印刷定位点——正是我们 V1 纸角/V2 母版标定路线的专利化印证（"任意性"有行业先例）。
- [一起中学扫描客户端帮助](http://zx-math.17zuoye.com/)：商用产品在 UI 里提供"扫描图片水平校正、模板位置确定、**偏移调整**"的操作流程——再次印证"微调进 UI"是标配。
- 有定位点时的**额外红利**（"加强利用"的具体化）：① 单应更稳（高对比已知形状，子像素质心，±0.5–1% 页面）；② 答题卡的**印刷结构本身是坐标系**——题目框、装订线、得分栏/总分栏的位置都是母版已知的，批注可精确落"第 N 题框右上角""总分栏格子里"，而不是"作答区附近"；③ 64K 答题卡纸小且厚、进纸稳，物理误差也小。

## 四、套打方案设计（内容规范层，叠在 09-14 几何层之上）

### 4.1 精度分级 × 痕迹类型准入矩阵（核心决策表）

"能打什么"由"对位精度"决定，不追求一步到位：

| 档 | 对位来源 | 预期精度 | 允许的痕迹 | 禁止的痕迹 |
|---|---|---|---|---|
| **Tier A 通用卷**（任意自印试卷，纸角/AI box） | 纸角检测 / staged 版面定位 box + 单应 | ±5–10mm | 每题 ✓/✗/得分（题号旁/角外）、页边批注+扣分说明、总分（首页右上）、页脚总评 | 字下划线、圈错字、行内批注、波浪线 |
| **Tier B 带定位点答题卡**（四角■，自动识别升级） | ■质心 + 单应（±0.5–1% 页面）+ 母版结构（题目框/得分栏） | ±3–6mm（含打印机） | Tier A 全部 + 每题得分**精确落题目框右上**、总分**落印刷的总分栏格内**、批注可短至行末 | 仍不做字词级圈画（打印机物理容差不支持） |
| **Tier C 事前布点印制版**（P3：从样卷重印母版+二维码/■/预留得分栏） | 二维码（身份+定位）+ 印刷结构 | ±2–4mm | Tier B 全部 + 客观题逐项对错落选项旁、接近商用一体机效果 | —（此时才谈"精细"） |

规则化：**每个痕迹元素自带 `minTier` 属性**（短痕=A、框内分=B、格内总分=B、逐项对错=C），版式层按当前卷的实测档位过滤——"任意卷都能用"（Tier A 保底）与"定位点加强"（自动升 B/C）由此统一，不需要用户理解档位。

### 4.2 痕迹内容规范（批注不圈写 + 总分必打）

复用 `paperMarkOverlays` 现有产物，套打版式新增四条规则（字号按 §4.2.1 层级表，无硬性下限——10pt 下限系 09-15 首版误引通用资料，同日经用户纠偏并复核后废弃）：

1. **页边批注**：右页边 8–10mm 安全区外起排，**批注用小字**（六号级别，见层级表），按题目 y 位置防重叠（`layoutMarginNotes` 平移到 mm 空间）；右边距 <15mm 的卷面自动降级为"行末编号 + 批阅报告全文"（现有 report 模式兜底）。
2. **每题短痕**：题号右侧/作答区角外（现有 `markStyle` 策略平移）；客观题只落符号/得分。
3. **总分（必打，用大字）**：固定落**首页右上角安全区内**（"86"大字 + "/100"半号小字的红分写法）；Tier B 且母版有印刷得分栏时落栏内。总分与每题分不一致时以逐题合成 `effectiveTotalScore` 为准（现状已是）。
4. **总评/页脚评语**：末页下安全区；不参与精细对齐（用户贴文原则）。

#### 4.2.1 字号层级表（09-15 二轮调研：真实可读下限 + 行业注释字号）

依据：① 印刷可读性研究（Legge 2011 综述及各指南）收敛于**正常阅读距离（40cm）下限 ≈8pt**，10–12pt 只是"舒适正文"，短批注 7–9pt 可读；② 中文印刷传统里**六号字（7.5pt≈2.56mm）正是脚注/报纸注释性小字的行业字号**——页边批注与它是同一类内容；③ 成年人手写正文 x 高 2.5–4mm、教师页边小批注 ≈3mm，换算中文全字约 8–11pt——**真老师的小批注本来就是这个量级，比试卷正文还小**。

| 痕迹元素 | 默认字号 | 依据 |
|---|---|---|
| 总分"86" | **18–22pt**（"/100"半号≈10pt） | 教师手写大分数 ≈7–8mm；层级对比 ≈3:1 |
| ✓ / ✗ 符号 | 12–14pt | 符号要瞬间识别 |
| 每题分数"9/12" | 11–12pt | 与教师手写题分（≈4mm）同量级 |
| 页边批注 | **7.5–8pt（六号）** | 中文注释字号惯例 + 教师小批注实况 |

非硬性要求：默认值可在预览里调整并记入任务/打印机档案。自适应时**只压内容不缩字号**（§4.2.2）。

#### 4.2.2 自适应排版规范（字多字少都好看）

- **宽度自适应**：每行可容纳数 = 批注栏宽(mm) ÷ 字宽(mm)，实际计算而非拍百分比；CJK 逐字断行，行尾自然；
- **纵向节奏**：批注落题目纵向中心，防重叠时**整行步进**下移（不是小数微移），行距 1.35，条与条之间空一行——视觉上有基线网格感；
- **结构固定**：首行「序号+分数」（略重），后续行扣分说明**悬挂缩进**（换行对齐文字而非对齐序号）；短批注不拉伸、左对齐、起点统一；
- **降级顺序**：先压缩行距 → 再砍内容（评语→扣分说明→只留序号分数，全文进批阅报告）→ 字号永不缩。
5. 不打：卷尾防混小字（套打模式下默认关，它本身是落点）、红框、底图（天然透明）。

### 4.3 边界模型（写进版式的硬约束）

```
页边(0mm) ── 硬件不可打印区(0–5mm, 保守) ── 安全线(8mm, 总分/批注类 10mm)
容差预算(叠加): 套印 ±1–2mm + 回纸歪斜(页远端 3–6mm) + 几何残差(V1 ±5–10 / V2 ±3–6mm)
```

- **落点准入**：任何痕迹的"偏移后包络"（落点 ± 容差 + 字宽）不得侵入相邻题作答区/学生字迹——版式层做碰撞检查（box 相邻题已知：量规+版面定位都有）；
- **避让优先级**：不遮题干 > 不遮学生答案 > 不遮已有批改 > 批注完整性（放不下就截断/降级，绝不换位硬塞）；
- **缩放强制**：打印前强提示"实际大小 100%/关适应页面/关无边框"；校准流程（§4.4）实测后存档案，后续静默打印参数写死根除；
- **纸张规格档案**：A4/A3/B5/8K(≈270×390)/16K(≈195×270)/64K 答题卡——按纸角检测四边的**宽高比自动匹配**候选规格（容差 2%），用户确认一次；`@page size` 联动；扫描仪图（纸边≈图边）自动判定，手机拍照按检测四角判定。

### 4.4 校准流程（试打 → 微调 → 档案）

```
[校准页] 含 100mm 横竖标尺 + 四角十字线 + 右上样例批注
  → 打一张到"用于套打的同款纸"上，量标尺(验证 scale) + 量十字线偏移(得 dx/dy)
  → 界面录入实测值 → 换算全局 scale/dx/dy → 再试一张确认
  → 存「打印机档案」(deviceName → {scale, dx, dy, 纸盒, 上次校准日期})
后续打印自动套用档案;换打印机/换纸盒/换纸重校
```

与商用方案对齐（CN110058824A 的人工调整、一起中学的偏移调整 UI）；dx/dy 以 ±0.5mm 步进；scale 以 0.1% 步进。

### 4.5 任意性设计（无定位点也成立）

基准链降级顺序（09-14 三级策略维持，本轮补充判定规则）：

1. **■定位点检测**成功（四角或 ≥3 个 + 时钟点）→ Tier B；
2. **纸角检测**（白纸对深背景，扫描仪图天然成立）→ Tier A，**任何卷零改造可用**；
3. **AI 粗定位+CV 精修**（复用 `completeSimple` 视觉调用模板）→ 背景杂乱时兜底；
4. **人工四点拖拽**（预填 ①/②/③ 结果）→ 逃生门，所有商用系统标配；
5. 四点拿不全时 ≥3 点即可解（CN101334814A 先例），2 点及以下 → 该卷降级为"合并打印"（照片+痕迹，现有 paper 模式）。

### 4.6 操作流（产品形态）

```
批阅痕迹 → 新增第三模式「套打回写」
  选纸张规格(自动建议) → 逐份基准点检测(进度+失败列表可人工四点)
  → 预览: 无底图 A4/mm 版式, 红痕实位, 底部提示进纸纪律
  → [打印校准页](首次/换打印机) → 录入实测 → 微调
  → [试打一份](对话框强提示 100%) → 对位确认
  → [全班套打]: 按名单排序出页, 屏幕逐份显示"正在打: 张三"
     —— 提示"按屏幕顺序放卷;每 5 份抽查一量"
```

## 六、风险与现实边界（向用户交底）

| 风险 | 量级 | 缓解 |
|---|---|---|
