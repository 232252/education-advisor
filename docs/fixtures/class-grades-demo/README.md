# 班级成绩分析 — 演示样例包

本目录是一份可导入的 **academics** 样例数据（3 场考试 × 5 名演示学生 × 4 科），用于本地预览班级成绩分析 Tab（分布、趋势、对比、打印）。

## 内容

| 文件 | 说明 |
|------|------|
| `config.json` | 科目（语数英 + 物理） |
| `exams.json` | 九月月考 / 十月月考 / 期中（学期 `2025-秋`） |
| `grades/*.json` | 按学生分文件的 `GradeRecord`（含 `fullMark` / `classRank`） |

演示学生名：`演示甲` … `演示戊`（请先在班级花名册中创建同名学生，或导入后改文件名/姓名以匹配现有花名册）。

## 如何加载

学业数据位于应用数据目录下的 `academics/`（开发时通常为 EAA 数据根下的 `academics`，与备份打包口径一致）：

1. **完全退出** Education Advisor。
2. 备份现有 `academics/`（若有）：整夹复制为 `academics.bak`。
3. 将本目录中的 `config.json`、`exams.json`、`grades/` **覆盖复制**到应用的 `academics/`（保留 `grades` 子目录结构）。
4. 重新打开应用 → 班级详情 → **成绩分析**；或在学业页查看录入/对比。

> 不修改工厂重置流程；仅文档级样例。若姓名与花名册不一致，趋势/排行会空，请对齐姓名或在班级中新增同名学生。

## 与二期功能的对应

- 多场均分趋势：三场同学期，科目筛选「全部」为百分制均分折线
- 自动 classRank：样例已按分数写入；之后在学业「录入」批量保存时也会按同分并列规则重算
- 打印：成绩分析工具栏「打印成绩单」或学业 → 考试管理
